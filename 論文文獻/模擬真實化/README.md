# 模擬真實化：參數來源

模擬真實化每個參數的出處。「實測」代表用我們自己實體車的 CSV 算出來，不是文獻。

| 項目 | 數值 | 出處 |
|---|---|---|
| 相機輸出更新率 | 平均 4.4 Hz，間隔照固定的三拍循環 0.11 / 0.11 / 0.45 s | **實測**：實體車 run10/12/13/14/15 的視覺 CSV，共約 2700 幀（`實體車子程式碼/實驗數據/`）。每 3 幀會做一次 D 同學的球場色彩分類，那一幀會多花約 0.34 s。 |
| 視覺迴路等效延遲 | 0.53~0.92 s，平均 0.70 s | **實測**：run12（Kp=1.5）共 8 次左右擺盪。每次拿「衝過頭的角度」除以「衝過零點時的角速度」。這個數字是整個迴路的延遲，包含相機緩衝區裡的舊幀、推論、UART 傳輸、馬達反應。 |
| 網球質量 | ITF 規格 56.0~59.4 g | ITF 網球規格（Type 2，跟 Type 1/3 相同）。⚠ 目前模擬**沒有採用**，原因見下面的「沒採用的項目」。 |
| 網球轉動慣量 | 0.6 m r² | 自己算的：橡膠殼厚約 3.2 mm、外徑約 6.7 cm，代入厚殼球公式 I = 2/5·m·(ro⁵−ri⁵)/(ro³−ri³)。實心球是 0.4，薄殼球是 0.667。Brody, *The Physics Teacher* 43, 503 (2005) 有量過網球的慣量，原文沒有讀到。 |
| 網球滾動阻力 | μr ≈ 0.01~0.03 | A. Singh et al., "Lawn tennis balls, rolling friction experiment and Trouton viscosity," arXiv:0809.4823 (2008)。PDF 在這個資料夾。 |
| 網球彈性 | e ≈ 0.75 | ITF 規格：從 254 cm 落下，反彈 135~147 cm，所以 e = √(141/254) ≈ 0.745（模擬本來就是 0.75，沒改）。 |
| 球場地面摩擦 | μ = 0.63 | ITF Court Pace Rating 公式：CPR = 100(1−μ) + 150(0.81−e)。中速硬地 CPR 是 35~39，取 e ≈ 0.81 代入，得到 μ ≈ 0.61~0.65。公式說明見 Sheffield Hallam University 的 Court Pace Rating 案例頁、ITF Court Surface Assessment 手冊。 |

| 陀螺儀雜訊 | 0.014 °/s/√Hz | BNO080 沒有公開陀螺儀雜訊密度，這裡借用同家族 BMI055 的規格書數值。在 1 kHz 取樣下，每筆的標準差 = 0.44 °/s。 |

## 沒採用的項目（試過，有數據）

- **網球質量 57.7 g**：用 `experiments/roller_pickup/pickup_test.py` 測了 12 次（W=42.5/50/55，海綿 kp=150/300/600），球全部卡在車頭前面，0/12。原因是現在的滾輪模型本來就跟 CAD 不一樣：位置是為了能撿起來才移過去的，海綿 k 值也是用 27 g 的球調出來的。所以要等 A 同學的 3D 檔，再加上實測的滾輪轉速，才能重新建立滾輪模型。在那之前先維持 27 g。
- **網球接觸剛性 1.23e4 N/m**（由 ITF 前向變形規格換算）：後車廂裡的球在 ODE 的軟接觸下會抖動，陀螺儀積分就跟著出錯。測法是後車廂放 6 顆球、直線開 15 s：剛性 1.23e4 時航向誤差 0.80~1.27°，1e5 時只有 −0.01~0.14°。這是 ODE 的數值問題，不是真實物理，所以維持 1e5。
